## README.md - Garabi Films Propuesta

**Garabi Films** es un proyecto de desarrollo web para la creación de un sitio de presentación profesional de una productora audiovisual. La web está diseñada como un expositor visual que destaca el catálogo de obras (largometrajes, series y cortometrajes), facilita el acceso a información de cada producción y ofrece un canal de contacto con el equipo.

El proyecto sigue una estructura multilingüe (`es/`, `eu/`, `en/`) con navegación minimalista. Incluye página principal con obra destacada, catálogo en formato de tarjetas responsive, fichas individuales y página de contacto. Se utiliza HTML, CSS  (`style.css` + hojas específicas) y está preparado para un despliegue sencillo en plataformas como Vercel.

**Estado actual:** Es un prototipo funcional con la estructura principal casi completa. Falta completar el contenido de algunos apartados (debido a la falta de info) optimizar responsive y terminar opcion multilingüe.

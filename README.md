## README.md - Garabi Films Propuesta

**Garabi Films** es un proyecto de desarrollo web para la creación de un sitio de presentación profesional de una productora audiovisual. La web está diseñada como un expositor visual que destaca el catálogo de obras (largometrajes, series y cortometrajes), facilita el acceso a información detallada de cada producción y ofrece un canal claro de contacto con el equipo.

El proyecto sigue una estructura multilingüe (`es/`, `eu/`, `en/`) con navegación minimalista inspirada en referencias del sector cinematográfico como Txintxua Films. Incluye página principal con obra destacada, catálogo en formato de tarjetas responsive, fichas individuales completas con material descargable y página de contacto. Se utiliza HTML semántico, CSS modular (`style.css` + hojas específicas) y está preparado para un despliegue sencillo en plataformas modernas como Vercel.

**Estado actual:** Prototipo funcional con estructura principal completa. Próximos pasos: completar catálogo, optimizar responsive y preparar versiones multilingües.
